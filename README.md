# Word Counter App

## How to run
To run this application, simply open `index.html` in a web browser.

## Features
- Upload a plain text document (.txt)
- Count the number of words in the uploaded document
- Display the word count on the page

## Accessibility
- The app is designed with semantic HTML5 elements for better accessibility.
- ARIA roles and properties are used where relevant to enhance the user experience.
- All interactions can be performed using the keyboard.

## Design tokens (CSS variables/palette)
- Background color: #f4f4f4
- Text color: #333
- Header background color: #007BFF

## API endpoints used
- None

## Attachments used
- `sample.txt`: A sample text file used to test the word counting functionality.

## Keyword coverage
| Keyword/Phrase                                 | Implementation Location                          |
